# 🍔 BurgerKing

A full-stack **MERN** based food ordering web application with features like dynamic product listings, cart management, secure payment integration, and an admin dashboard. Designed for smooth user experience and scalable operations.

## 🚀 Features

### 🛒 Customer Side
- Browse and search dynamic food items
- Add/remove items to/from cart
- Place orders with **Razorpay** (UPI & cards)
- **Google OAuth** for fast and secure login

### 🧑‍💼 Admin Panel
- Manage products (add, update, delete)
- Control menu visibility and business hours
- View orders and payment status

### 📦 Order Handling
- Live order status tracking
- Automatic cart clearing post-checkout
- Responsive UI for mobile and desktop

## 🧑‍💻 Tech Stack

| Tech | Usage |
|------|-------|
| **Frontend** | React.js, Tailwind CSS, Redux Toolkit |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB with Mongoose |
| **Authentication** | JWT, bcrypt, Google OAuth |
| **Payment** | Razorpay Integration |
| **Others** | Cloudinary, Postman, GitHub

## ⚙️ Setup Instructions

1. **Clone the repo**

```bash
git clone https://github.com/MohsinKing2002/BurgerKing.git
cd BurgerKing

npm install
cd client && npm install

#setup env for server and client
#server start.
npm run dev

#client start.
npm start
```
